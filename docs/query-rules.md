# 查询和排序规则

queryTasks 接收任务数组、过滤条件和参考日期。多项过滤条件取交集：只有全部满足才会保留。空白搜索词与没有搜索词效果相同。

搜索覆盖标题、备注和标签，忽略大小写，去掉搜索词首尾空白。它使用普通子串匹配，不解释正则表达式，也不执行用户输入的 HTML。普通搜索会保留已完成任务；是否完成由状态条件决定。

| 截止条件 | 保留范围 |
| --- | --- |
| overdue | 截止日早于参考日，且尚未完成 |
| today | 截止日等于参考日，且尚未完成 |
| none | 没有截止日，包含已完成任务 |

例如 search=review、priority=high、status=todo、due=today 只返回今天到期、待开始、高优先级且文本匹配 review 的任务。status=done 与 due=today 的交集为空。

sortTasks 返回一个新的数组，不改变输入顺序。priority 按 high、medium、low；due 按日期升序，空日期放在末尾；newest 按创建时间降序；title 使用 zh-CN 名称比较。主要条件相同后，先比较创建时间降序，再比较 ID 升序，使结果可重复。

查询与排序返回的任务对象仍引用输入任务。若调用方需要编辑结果，应使用 updateTask 等状态函数，而不是直接修改查询结果。
