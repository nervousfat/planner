# 本地数据与恢复

浏览器版使用 localStorage 保存任务，没有服务端账号或云同步。数据属于当前浏览器配置和网站来源；127.0.0.1 与 localhost、不同端口、不同浏览器不会自动共享同一份任务。

迁移步骤：先在原来源导出 JSON 备份，保留一份副本；在新来源打开应用，导入文件并核对任务数量。导入会替换当前列表，不会与现有任务合并，因此迁移前也应导出目标列表。

清理浏览器站点数据、删除浏览器配置或结束某些隐私会话可能删除本地记录。备份文件才是独立于浏览器的副本，建议在批量编辑和导入前保存。

出现保存失败提示时，当前操作尚未写入本地存储。检查浏览器是否禁止站点存储、磁盘或站点配额是否已满；不要反复清除站点数据试错。若页面仍可导出，先导出当前可读取的数据。

损坏或不符合版本的 JSON 不会被部分导入。可以将文件复制一份后按 backup-format.md 的字段契约排查，保留原文件以便恢复。不要通过手工改 version 数字把未知格式伪装成受支持格式。

本地静态服务仅监听本机。通过 HTTP 地址访问应用，并保持固定端口；直接双击 HTML 的存储和模块加载行为不可靠。
